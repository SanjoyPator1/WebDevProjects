# String Calculator TDD

This project implements the String Calculator TDD.

## Problem Description

Create a simple String calculator with a method signature:

```python
def add(numbers: str) -> int
```

The method can take a string of comma-separated numbers and will return their sum.

## Running the Tests

To run the tests:

```bash
python -m unittest test_string_calculator.py
```

## TDD Approach

This project was implemented using Test-Driven Development (TDD), following the Red-Green-Refactor cycle:

1. Write a failing test (Red)
2. Write the simplest code to make the test pass (Green)
3. Refactor the code while keeping the tests passing

Each commit in the repository represents a step in this process, showing how the implementation evolved.
